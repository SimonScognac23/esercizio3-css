In questo progetto, ho applicato diverse tecniche di styling CSS per migliorare il layout e l'interattività della pagina web. Ecco una panoramica delle modifiche apportate:

Tipografia:

Ho utilizzato due font personalizzati: "Roboto" per i titoli (h1, h2, h3) e "Poppins" per i paragrafi e gli elementi di navigazione, assicurando una tipografia chiara e moderna.
Il peso del font per i titoli è stato impostato a 600, mentre per i paragrafi e la navigazione è stato impostato a 300 per un aspetto più leggero.
Layout e Flexbox:

Ho implementato il sistema di layout Flexbox per il design reattivo. Ad esempio, la sezione dell'header utilizza flex-direction: column per centrare il titolo, e la classe Flexbox è utilizzata per visualizzare i contenuti in una riga con spazio tra gli elementi.
Le sezioni main, aside e footer sono state stilizzate per allineare correttamente i contenuti e adattarsi alle dimensioni dello schermo usando le media query.
Sfondi e Miglioramenti Visivi:

È stato aggiunto un colore di sfondo (blu) alla sezione #articolo, mentre la classe .index-photo include un'immagine di sfondo personalizzata con impostazioni specifiche come background-size: cover per garantire che si adatti correttamente.
Sono stati aggiunti effetti hover per cambiare il colore di sfondo di .articolo2 da verde a "whitesmoke", migliorando l'interattività.
Navigazione:

È stata creata una barra di navigazione personalizzata utilizzando Flexbox, con un effetto hover sui link che cambia il colore del testo e aggiunge un bordo inferiore per un aspetto più interattivo e moderno.
Footer ed Elementi Interattivi:

È stato stilizzato un footer con una classe disco che include un logo animato che si muove quando si passa il mouse sopra il footer, grazie all'animazione @keyframes. Questo fornisce un'esperienza utente dinamica e coinvolgente.
La classe .icon è fissa nella parte inferiore destra della pagina e anima un effetto di rimbalzo, che si ripete all'infinito per un appeal visivo.
Responsività:

Le media query sono state utilizzate per adattare il layout alle dimensioni dello schermo più piccole. Ad esempio, gli elementi di navigazione si impilano verticalmente sui dispositivi mobili, e vari elementi come .aulab e .Flexbox si adattano nella loro dimensione e layout per garantire che la pagina rimanga user-friendly su schermi più piccoli.
Complessivamente, queste modifiche contribuiscono a un design attraente, moderno e reattivo, garantendo una buona esperienza utente su dispositivi di diverse dimensioni.

In this project, I applied various CSS styling techniques to enhance the layout and interactivity of the webpage. Here’s a breakdown of the changes made:

Typography:

I used two custom fonts: "Roboto" for headings (h1, h2, h3) and "Poppins" for paragraphs and navigation items, ensuring clear, modern typography.
The font-weight for headings was set to 600, while for paragraphs and navigation it was set to 300 for a lighter feel.
Layout and Flexbox:

I implemented the Flexbox layout system for responsive design. For example, the header section uses flex-direction: column to center the title, and the Flexbox class is used to display content in a row with space between elements.
The main, aside, and footer sections were styled to align content properly and to adjust based on the screen size using media queries.
Backgrounds and Visual Enhancements:

A background color (blue) was added to the #articolo section, while the .index-photo class includes a custom background image with specific settings like background-size: cover to ensure it scales appropriately.
Hover effects were added to change the background color of .articolo2 from green to "whitesmoke", enhancing interactivity.
Navigation:

A custom navigation bar was created using Flexbox, with a hover effect on the links that changes the text color and adds a border-bottom for a more interactive and modern look.
Footer and Interactive Elements:

A footer with a disco class was styled to include an animated logo that moves when hovering over the footer, thanks to the @keyframes animation. This provides a dynamic and engaging user experience.
The .icon class is fixed at the bottom right of the page and animates with a bouncing effect, which repeats infinitely for visual appeal.
Responsiveness:

Media queries were used to adjust the layout for smaller screen sizes. For example, the navigation items stack vertically on mobile devices, and various elements like .aulab and .Flexbox adjust their size and layout to ensure the page remains user-friendly on smaller screens.
Overall, these changes contribute to an attractive, modern, and responsive design, ensuring the webpage provides a good user experience across different devices.
